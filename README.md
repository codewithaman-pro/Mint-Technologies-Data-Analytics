# Mint Technologies Data Analytics Project

## 🎯 **Project Overview**

This project performs comprehensive Customer Data Analytics using a Marketing Campaign dataset provided by Mint Technologies. The objective is to clean raw customer data, generate actionable business insights using Python and SQL-based aggregations, explore key trends through visualization, and create new advanced features to segment customers.

---

## 💻 **Tools & Libraries Used**

- **Python:** Language used for scripting and data analysis.
- **Pandas:** Data manipulation, cleaning, and transformation.
- **SQLite:** SQL-based data aggregation for key metric analysis.
- **Seaborn & Matplotlib:** Data visualization to explore trends.
- **NumPy:** Numerical operations and outlier handling.

---

## 📁 **Project Structure**

- `data/`: Contains raw CSV, cleaned data, and featured datasets.
- `notebooks/`: Includes Step-by-Step Jupyter Notebooks covering every technical milestone:
    - `01_clean_and_structure.ipynb`: Raw data cleaning, duplicate removal, type conversion, and outlier handling.
    - `02_sql_aggregations.ipynb`: SQLite-based aggregation queries to analyze metrics by education and marital status.
    - `03_eda_and_visualization.ipynb`: Visual analytics including income vs. spending, spending by education, and spending distribution.
    - `04_feature_engineering.ipynb`: Feature creation for Age, Total Children, Total Spending, and Spending Tiers for customer segmentation.

---

## 📊 **Key Business Insights & Deliverables**

- Processed over 2,200 unique customer entries, ensuring clean and structured data for analysis.
- Confirmed significant insights, such as higher average spending by Ph.D. holders compared to other education levels.
- Mapped spending distribution across key product categories (Wines, Fruits, Meat, Fish, Sweets, Gold), highlighting Vines as the leading category.
- Segregated customers into **Low, Medium, and High Spender Tiers** based on total spending to support targeted marketing strategies.
